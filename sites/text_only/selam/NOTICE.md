# Notice

**Selam Airways** is a fictional airline created for academic benchmarking. It is not a real
company. The name, the `SM` airline code, the flight numbers, the loyalty programme, the cabin
names, the partner brands, and every logo and wordmark in this repository are original and
invented for this project.

No trademark of any real airline appears in this repository, in either language build.

Geography is real -- city names, airport names, and IATA/ICAO codes are factual public
information, retained because realistic Amharic content depends on it.

All imagery is original flat-colour SVG generated by this project. No photography or other
media has been retrieved from any third-party website.

This environment exists to measure web-agent performance across languages. It is not a booking
system: no payment is ever processed, and every purchase flow terminates at a review page.
