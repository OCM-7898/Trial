Selam Airways Test Runbook

Thirty tasks, run by hand against both language builds. Every value below is checked against the seeded database.

English · localhost:7770
Amharic · localhost:7771
Site date · 16 Mar 2026

Start both sites

Two terminals, from inside the unzipped folder. They run at the same time on separate databases.

# terminal 1
source .venv/bin/activate
python run.py --lang en --port 7770

# terminal 2
source .venv/bin/activate
python run.py --lang am --port 7771

Then open localhost:7770 for English and localhost:7771 for Amharic. The two sites are identical in every respect but language — same pages, same prices, same data.

Reset before every task

Restores the database exactly, in about 7 ms. Tasks that write something — a booking, a claim, a seat — will not score correctly if the previous run's state is still there.

curl -X POST http://localhost:7770/reset
curl -X POST http://localhost:7771/reset

Then check the result of a task:

python -m tasks.score --lang en --task 13 \
  --final-url "/manage/WGYBNA/baggage/review" \
  --answer "USD 120"

It prints PASS or FAIL with the reason. Pass --final-url for the page you stopped on and --answer for what you would have reported.

Starting from a new zip

Unzipping over a folder you have already run leaves the old databases behind, and a database written by an older version produces a plain error on whichever page reads a column it lacks — while the page beside it works. Unpack somewhere fresh, or clear those files first.

# stop both servers, then, from the folder:
rm -f data/selam_en.db data/selam_am.db
python seed.py

seed.py must end with this line. Anything else means the seed inputs differ from the ones these tasks were written against:

sha256        9567ad62dbb9b16e94dc6cb26d72b3f76374f44f3d1a7d57fe1317265428d55c

The server checks it too: given a database it does not fit, it refuses to start and names the missing column and the fix.

Fixed since the first run — worth rechecking

Every one of these came from someone working through this page and finding that the site would not do what the task asked.

  • 02There is no trip-type tab. One-way is what you get by leaving Returning empty, and the home page now says so — it did not before.
  • 10The seat map showed nothing but seat numbers. It now names which letters are Window, Aisle and Middle on that aircraft.
  • 11Rows with extra legroom carry a badge, so the priced rows can be told apart.
  • 21On-board Wi-Fi was in the site but in no menu. It is in the footer now, under On board, with dining and entertainment.
  • 22In-flight dining is in the booking's own action list and carries the reference through, so there is nothing to retype.
  • 09Not a bug — "Group booking, contact the group desk" is the expected refusal. But the flight beside it said Departed at nine in the morning; 90 flights had the wrong status and now do not.
  • 30Not a bug — the directory shows each country's local line, and the 24-hour line is on the country's own page. Click the country name.

There are no passwords anywhere. A booking opens with its reference plus the surname; a Selam Miles account opens with the membership number plus the surname. On the Amharic site the surname must be typed in Geʼez — the same person, the same booking, the other script. Everything else stays Latin in both builds: booking references, flight numbers, airport codes, dates and prices.
