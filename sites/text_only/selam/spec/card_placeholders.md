# Card placeholders

Generated by `tools/make_placeholders.py`. Original geometric SVG in the Selam Airways palette; nothing here is derived from any real airline's imagery, and no photography was fetched for this build.

They carry no text: a caption inside the file would render as Latin script on the Amharic pages. Captions are alt text on the page, translated through `t()`.
